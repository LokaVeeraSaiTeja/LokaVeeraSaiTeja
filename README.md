## 🚀 Featured Projects

### 1. 🔢 [Verilog Sequence Detector](https://github.com/LokaVeeraSaiTeja/Verilog_SequenceDetector)

Designed sequence detectors for the binary pattern `1011` using Mealy and Moore finite-state machines.

- Implemented FSM-based RTL using Verilog HDL.
- Developed testbenches to verify sequence detection.
- Simulated and analyzed state transitions using AMD Vivado.
- Explored state diagrams and state transition tables.

**Technologies:** Verilog HDL · FSM · RTL Design · Vivado

Exploring RISC-V processor architecture and FPGA implementation.

- Working toward simulation-based verification and FPGA deployment.

**Target Platform:** Basys 3 · Artix-7 FPGA
